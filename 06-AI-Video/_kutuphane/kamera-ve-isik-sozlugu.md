# Kamera & Işık Sözlüğü (prompt'ta kullanılacak İngilizce terimler)

> Prompt kalitesinin yarısı doğru terimdir. "Kamera yaklaşsın" yerine `slow dolly push-in` yazınca model ne istediğini anlar. Her satır: **EN terim** — TR açıklama — ne zaman kullanılır.

## 1. Çekim ölçeği (shot size)

| EN | TR | Kullanım |
|---|---|---|
| `extreme close-up (ECU)` / `macro shot` | aşırı yakın / makro | damla, doku, kıvam, altın tanecik, göz |
| `close-up (CU)` | yakın plan | ürün tek başına, el + ürün |
| `medium close-up (MCU)` | omuz-baş | konuşan kişi (reels standardı) |
| `medium shot (MS)` | bel plan | kullanım anı, masa başı |
| `wide shot (WS)` / `establishing shot` | genel plan / tanıtım planı | mekan, klinik koridoru, havuz kenarı |
| `top-down` / `flat lay` / `overhead shot` | tepeden | ürün seti, rutin dizilimi |
| `product hero shot` | kahraman ürün planı | tek ürün, merkez, temiz zemin |

## 2. Açı (angle)

| EN | TR | Not |
|---|---|---|
| `eye-level` | göz hizası | nötr, güven |
| `low angle` | alt açı | ürünü heybetli gösterir (lüks) |
| `high angle` | üst açı | samimi, küçültür |
| `45-degree angle` | 45° | ürün ambalajı için en okunaklı açı |
| `dutch angle` | eğik | gerilim — kozmetik/klinikte kullanma |
| `over-the-shoulder` | omuz üstü | kullanım anı, telefon ekranı |

## 3. Kamera hareketi (movement) — **her prompt'ta biri mutlaka yazılır**

| EN | TR | Ürün/kurumsal için |
|---|---|---|
| `locked-off` / `static shot` / `the camera does not move` | sabit | makro doku, damla — en güvenli |
| `slow push-in` / `dolly in` | yavaş yaklaşma | hero ürün, hook |
| `slow pull-out` / `dolly out` | yavaş uzaklaşma | kapanış, set gösterimi |
| `orbit` / `arc shot` / `the camera circles the product` | ürün etrafında dönüş | 360° ürün — 8 sn'de en fazla 90–180° iste |
| `pan left/right` | sağa-sola çevrinme | mekan gezdirme |
| `tilt up/down` | yukarı-aşağı | şişe boyu, bina cephesi |
| `tracking shot` / `follow shot` | takip | yürüyen kişi, koridor |
| `crane up` / `rising shot` | vinç yükselme | dış cephe, tanıtım |
| `handheld, subtle shake` | el kamerası | samimi/belgesel — kozmetikte az |
| `gimbal, smooth glide` | gimbal, kayan | modern reels hissi |
| `rack focus from A to B` | netlik geçişi | ön plandaki portakaldan şişeye |
| `dolly zoom` / `vertigo effect` | vertigo | dramatik; markalar için nadir |
| `FPV drone` / `fly-through` | drone geçişi | mekan, bina — Higgsfield preset |
| `whip pan` | hızlı çevrinme | geçiş efekti, kurguda birleştirme |
| `slow motion` (`120 fps feel`) | ağır çekim | damla, sıçrama, saç |
| `time-lapse` | hızlandırılmış | bulut, bitki büyümesi, gün dönüşü |

## 4. Lens & optik

| EN | Etki |
|---|---|
| `100mm macro lens` | doku/damla; çok sığ alan derinliği |
| `85mm portrait lens` | yüz; arka plan yumuşak |
| `50mm` | doğal, göz gibi |
| `35mm` | mekan + kişi birlikte |
| `24mm wide` | mimari, koridor (kenarlar hafif bükülür) |
| `anamorphic lens, oval bokeh, horizontal lens flare` | sinema hissi (kozmetikte abartma) |
| `shallow depth of field, f/1.8` | arka plan bulanık, ürün net |
| `deep focus, f/8` | her şey net (flat lay) |
| `bokeh` | ışık lekeleri arka planda |
| `soft focus foreground element` | ön planda bulanık yaprak/portakal — derinlik katar |

## 5. Işık

| EN | TR | Marka eşleşmesi |
|---|---|---|
| `soft diffused window light` | yumuşak pencere ışığı | Nefin, Humentis — varsayılan |
| `golden hour backlight` | gün batımı arka ışık | lifestyle, havuz |
| `overcast daylight` | kapalı hava | nötr, dürüst — kurumsal |
| `high-key lighting` | aydınlık, gölgesiz | temiz kozmetik, klinik-temiz |
| `low-key lighting` | karanlık, dramatik | lüks gece — Nefin'de YASAK |
| `rim light` / `edge light` | kenar ışığı | cam şişe silüeti |
| `specular highlights on glass` | camda parlama | amber şişe için şart |
| `caustics` / `water light patterns` | su ışık oyunları | havuz kenarı çekimi |
| `dappled light through leaves` | yaprak arası benekli ışık | botanik, doğal |
| `practical lights` | kadrajdaki gerçek lambalar | ofis, akşam |
| `studio softbox, seamless backdrop` | stüdyo | e-ticaret ürün |
| `volumetric light, light rays` | ışık hüzmesi | kapı açılışı (Humentis B-roll) |
| `color temperature 3200K warm` / `5600K daylight` | sıcak / gün ışığı | grade ile uyumlu seç |

## 7. Hazır kombinasyonlar (kopyala)

**Makro doku (kozmetik):**
`extreme close-up, 100mm macro lens, shallow depth of field, locked-off camera, soft warm window light from the left, specular highlights, slow motion`

**Hero ürün (kozmetik):**
`product hero shot at a 45-degree angle, 85mm lens, slow dolly push-in, soft diffused window light with a subtle rim light, cream seamless background`

**Sakin mekan (klinik):**
`wide establishing shot, 35mm lens, slow gimbal glide forward, overcast daylight through linen curtains, muted filmic grade`

**Lifestyle el + ürün:**
`medium close-up, 50mm lens, subtle handheld, golden hour backlight, shallow depth of field`

**Kurumsal ofis / ekip:**
`medium shot, 35mm, slow tracking shot, overcast daylight, clean neutral grade, natural skin tones`
